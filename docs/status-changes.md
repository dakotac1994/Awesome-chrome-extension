# Status Changes

Notable events affecting extensions in this list, newest first. This log is updated when an entry's status materially changes.

## 2026

- **August 31, 2026 — Manifest V2 purge.** Google removed remaining MV2 extensions from the Chrome Web Store. Casualties relevant to this list's scope: the full **uBlock Origin** (only uBlock Origin Lite remains for Chrome), **uMatrix** (development had already ended in 2020), **NoScript** (Chrome listing), **Marinara** (Pomodoro), and the original **Cookie AutoDelete** (superseded by the V3 fork, which is listed).
- **March 2026 — LanguageTool extension goes premium-only.** The browser extension now requires a Premium subscription; the web version stays free and the extension still works against a self-hosted server. Labeled *(proprietary)*.
- **January 2026 — Bitdefender TrafficLight renamed.** The extension is now **Bitdefender Web Sage**; the old CWS URL redirects to the new listing (same extension ID).
- **2026 — Nimbus rebrands to FuseBase.** Nimbus Screenshot / Nimbus Capture is now sold under the FuseBase brand; the Chrome Web Store listing is unchanged.

## 2025

- **~July 2025 — Pocket discontinued.** Mozilla shut down Pocket; the Save to Pocket extension is dead. Documented in Notable exclusions.
- **January 2025 — Web Vitals extension retired.** Google folded its features into the DevTools Performance panel.

## 2024

- **Late 2024 — EditThisCookie (original) removed from the CWS.** The MV2 original by fcapano was removed; a community MV3 fork is listed instead.

## Earlier

- **2022 — LastPass breach.** Threat actors stole encrypted vault backups from LastPass cloud storage (disclosed December 2022). The extension is listed with a neutral description; evaluate accordingly.
- **2021 — The Great Suspender removed for malware.** Removed from the CWS after an ownership change introduced malicious code. Memory-saving is now handled by Chrome's built-in memory saver.
- **2020 — uMatrix development ends.** gorhill archived the project.
- **2019 — Avast/AVG extensions removed from Mozilla's store.** Research found detailed browsing-history harvesting. The Chrome listing (now "Avast Online Security & Privacy") discloses telemetry; the extension is excluded from this list.
